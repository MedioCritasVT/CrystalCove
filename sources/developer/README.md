# Developer source workspace

Code, tests, declarations, build inputs, examples and reproductions are source files. Runtime credentials, private notes, local agent memory databases, system tokens and downloaded proprietary libraries are **not** public source.

Use [Portal source](../../conflux/portal-app/), [platforms](../../conflux/platforms/), and [first-run test notes](../../docs/PLAYER_FIRST_RUN_TEST_STATUS_2026-11-13.md) as examples. Keep host-only experiments under `~/Conflux/SourceFiles/developer/` or ignored `sources/developer/scratch/`.

An open interface architecture can be copied without assuming that visiting the Portal authorizes downloads, Git writes, game launches, account discovery or software installation.
