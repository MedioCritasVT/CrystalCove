# Artwork sources

Layered artwork, Blender files, model rigs, animation tests, sketches and character panels belong to the creator's source collection. Reusable, intentionally published reference plates are currently indexed in [concept-art/reference-art](../../conflux/concept-art/reference-art/README.md). A panel's filename does not itself establish an approved design.

Use `~/Conflux/SourceFiles/artwork/` for **editable original projects** and keep `sources/artwork/originals/` local-only if working inside a Git clone. Publish small, approved outputs separately. Do not upload private work, proprietary third-party artwork, or raw personal material simply to make a Portal pet work.
