# Music sources

Original MP3s, WAV masters, stems and project files are creative **source** materials. Preserve them in `~/Conflux/SourceFiles/music/masters/` or another user-controlled source folder outside public Git unless deliberately published.

The public [soundtrack catalog](../../conflux/soundtrack/catalog.json) holds metadata. The [full SHA-256 manifest](../../conflux/soundtrack/RELEASE_SHA256SUMS_FULL.txt) validates the eleven supplied recordings. The separate [legacy manifest](../../conflux/soundtrack/RELEASE_SHA256SUMS.txt) retains the initial seven-recording import edition.

Actual downloadable public MP3s belong to an approved GitHub Release **as separate assets**, not only in a source ZIP or Git checkout. A catalog title and a filename are never proof of a publicly accessible MP3 or transfer of rights.

Local Portal installation is explicit: choose **Music options → Install soundtrack ZIP once** and select a verified 7- or 11-recording archive. No upload to GitHub occurs.
