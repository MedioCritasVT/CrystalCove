Import and interpretation policy

The app does not use AI or automatically infer canon. Imported text is treated as source material. Your summary is stored separately from the original text. Existing entries are append-only; corrections should be entered as a new record referencing the old one. Exports place explicitly Approved entries in a dedicated canonical section of Conflux.md.

Storage and portability

Committed entries are saved only in this browser's localStorage. Download readable Ledger (.md) exports one human-readable Conflux.md file containing all committed entries. Download restorable backup (.json) saves all committed entries for future import using Restore from backup. Neither export automatically updates later; download new snapshots after new commits. Browser clearing, private mode, or switching browsers can erase local data, so keep a JSON backup somewhere safe. Restoring a backup replaces current local entries only after your confirmation. No data is sent to a server by these controls.
