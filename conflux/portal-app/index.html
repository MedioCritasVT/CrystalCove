Local discovery · Already installed?

Already cloned or downloaded?

If the playable game is already extracted, don't download it again. Choose the folder where you put it. The Portal looks only in that folder and a few levels below for PlayConflux.sh; no game will start while searching.

Cloned just this GitHub repository? That gives you project files, but not necessarily the packaged game. Use the game release above if PlayConflux.sh is missing.

Meet the Nodes

Medio introduces balance and readable combat rhythm. Ratio suggests precision, Nexus coordination, Specula observation, and Limen transitions. These are guiding designs: not all realm mechanics are complete in V0.1.

What to expect

The world, characters and menus are evolving. Some locations and progression systems are prototypes, and the current game is Linux-only. If something breaks, note the game version, Linux distribution, graphics card, location in the game, and steps that led to the problem.

Updates come only from the official public CrystalCove main branch. A check retrieves GitHub's latest commit information, but does not change your working files. Nothing installs automatically.

Your local notes and other uncommitted work are never reset, stashed, or deleted. Git will refuse any update that would overwrite them.

If you're previewing a development branch, Update can safely switch to main first. If Git cannot switch without affecting your edits, it stops and tells you why.

One-time setup · Linux

Open Conflux from your Applications menu

Install a shortcut for your current Linux user. Afterward, use your desktop's app search to open Conflux Portal. It starts the local service or reuses the one already running, then opens Firefox or your default browser.

No system-wide install, administrator password, or root permissions needed.

This development version updates its existing Git checkout. It does not install or update the separately distributed Unreal game archives.
