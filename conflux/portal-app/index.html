Your first steps in Conflux

No GitHub, coding, or AI knowledge required. Start with the game, the books, or simply explore the Portal. This is a long-term work in progress; new features and platforms are coming later.

1. Explore

Read the project records and choose which parts interest you.

2. Install selectively

Download the Linux game or configure a local application. Cloning the repo alone does not install or launch software.

3. Keep authority visible

Draft, reviewed, approved, tested and deployed are separate states. A Node message is not an authorization.

Want the complete guide? Read the New Player Manual for controls, saving, the five Nodes, available features, and what is still being built.
