CONFLUX — OFFLINE BROWSER EDITION

1. Extract this ZIP.
2. Open Conflux.html in Zen, Firefox, Chrome, or Edge.

No installation, terminal, server, account, or Internet connection is required.
Keep WebGL / hardware acceleration enabled for 3D. Zen on Bazzite should work;
Zen/Bazzite itself has not been tested here. A current desktop browser is recommended.
If your browser cannot initialize WebGL, the journal game remains available.

WASD / arrows: move. Shift: run. Drag: orbit. Scroll: zoom. E: interact.
Controls & map: quick travel. Character view: front view. Journal view: original interface.
Touch controls appear on narrow screens.

Progress saves in this browser when local-file storage is permitted. Private browsing,
file moves, or browser policies can affect retention. There is no cloud sync.

The avatar is a stylized reference-inspired model, not a production character asset.
Realm portals currently change the sanctuary lighting palette; they share geometry.
Dialogue is scripted, not live AI. There is no host OS integration.

The source/ folder contains the editable version. Serve that folder with:
python3 -m http.server 4173
Then open http://localhost:4173 in your browser.
The standalone Conflux.html above does NOT require this server.
