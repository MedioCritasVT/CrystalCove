# Conflux — Sanctuary browser study

## Download and play

Download [Conflux-Offline.zip](downloads/Conflux-Offline.zip) using GitHub’s **Download raw file** button, extract it, and open `Conflux.html` in Zen or another current WebGL-capable browser. The self-contained HTML needs no server or Internet connection. Zen/Bazzite has not been tested directly.

Editable source is in this directory; the original notes vault is preserved above it. The four unique supplied design references are retained in `design/`.

## Run the editable source

Run `python3 -m http.server 4173 --bind 0.0.0.0` from the `conflux` directory. Open the served page in a browser. No dependency install, build step, API key, or model service is needed. All art, scripts, and styles are local.

## Play

Start in the Cove with Medio. Invite Nodes through the gacha-style invitation control; manage your roster in Companions, keep up to three party members, and select a card to change the leader. Invitations have equal 25% probabilities for Ratio, Specula, Nexus, and Limen; duplicates refund the invitation. Refill freely through Companions.

Choose a topic to talk with the party, hear one relevant perspective at a time, or pause and leave. Dialogue is authored, not generated by live AI. Realm travel is freely available. Notice the world for a quiet moment without progression rewards or attendance requirements.

Gather materials, craft a Chaos Emerald and Spirit Spark into a Soul Crystal, and awaken the Sapphire Grimoire. Its comparison puzzle distinguishes syntax from behavior, including boundary cases. Correct the operator to `>=`, test, then explicitly apply to the fictional gate. The block display and gate preview illustrate the result. No Python or arbitrary code is executed; no host permissions are requested.

Progress is saved under `conflux-codex-study-v2` in browser local storage. Reset affects only this study. The previous prototype's save is preserved.

## 3D sanctuary

The entry page now starts in a Three.js 3D environment. Walk with WASD or arrow keys, hold Shift to run, drag to orbit the camera, and scroll to zoom. Approach a station and press E or select its prompt. Touch movement buttons are provided on narrow screens. Controls & map offers quick travel to each station. Character view turns the reference-inspired avatar toward the camera. Journal view keeps the earlier interface available with exactly the same inventory and progress.

The character is a custom stylized mesh interpretation of the supplied imagery: dark hair, ruby eyes, black feathered wings, gold circlet, red halo, ivory skirt, and gold details. It has animated arms, legs, wings, and idle motion. Party selection changes the leader and halo accent; separate production character models are not implemented.

Stations cover party management, invitations, materials, crafting with Daemon, the Grimoire, topic-based conversations, and three realm portals. The realms currently share the sanctuary geometry with different lighting palettes. Applying the Grimoire puzzle also removes the world gate's barrier and lights it gold. Progress persists; player position and camera reset on reload.

Three.js 0.180.0 is vendored locally under `vendor/` with its MIT license. Its npm tarball was checked against the registry's SHA-512 integrity. No network requests are needed at play time. A WebGL-capable browser is required for 3D; if initialization fails, the journal interface remains available.

Browser smoke checks are in `checks/browser_3d.py`; they use Python Playwright and installed Chromium. Run them against the server on port 4173. They exercise real rendering, movement, station interactions, crafting/Grimoire, invitations, dialogue, portals, shared journal state, and mobile controls. Software WebGL may be slow; hardware acceleration is recommended for play.
